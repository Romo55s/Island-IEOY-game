# Kenney CC0 audio library

This project keeps its original procedural WAV cues and supplements them with four sounds from Kenney's CC0 packs.

- [Interface Sounds](https://kenney.nl/assets/interface-sounds): `select_001.ogg`, `confirmation_001.ogg`
- [RPG Audio](https://kenney.nl/assets/rpg-audio): `bookFlip1.ogg`, `metalLatch.ogg`

Both packs are dedicated under Creative Commons CC0 1.0. The original pack license text is included alongside each selected file. The cues are used in game interactions and can also be auditioned on `/sound-test`.
