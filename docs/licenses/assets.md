## Audio assets

No audio file is currently distributed. `public/audio/manifest.json` reserves stable cue IDs with `available: false`; each resolves to the required silent fallback. Before enabling a cue, replace its placeholder license record with the real source URL, author, redistribution license, and attribution, add the local browser-ready file, and set `available: true`.

Generated silence, a missing URL, or a runtime fallback does not grant a license to a future replacement asset.
