## Validator Warnings

1. The normal-mapped material has no tangent attribute, so the runtime would generate tangent space. The PS1 runtime derivative should remove the normal map unless visual review proves it necessary, which also removes this warning and reduces texture cost.
2. The skinned mesh node is not a scene root. Verify animation and scaling after optimization; do not compensate blindly in every runtime instance.
